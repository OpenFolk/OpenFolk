# Support

- **Questions about using OpenFolk:** ask in [Discussions](https://github.com/OpenFolk/OpenFolk/discussions), or check the README and the `docs/` folder first.
- **Bug reports and feature requests:** use the [issue templates](https://github.com/OpenFolk/OpenFolk/issues/new/choose).
- **Security problems:** see [SECURITY.md](SECURITY.md) and report privately.

OpenFolk is maintained in our spare time. We read every issue, but response times vary.
